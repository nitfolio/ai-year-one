# Neural Networks From Nothing
### A complete self-taught path from weak math to AI research

**Author's note to the reader:** This book was written for one person who had one year, no mentor, and a starting point of "bad at math, below average at programming." It assumes nothing. It is designed to be worked through alone.

Start date: 5 August 2026 · Target: 5 August 2027

---

## How to use this book

Read [**Chapter 0 first, completely, before anything else.**](obsidian://open?vault=aiml&file=chapters%2Fch00-how-to-learn-alone) Then skim [**Appendix F**](obsidian://open?vault=aiml&file=chapters%2Fappendix-f-learners-playbook) — it's the companion to Chapter 0, and the one you'll come back to on the bad weeks. It is not an introduction you can skip. It contains the method that makes the remaining chapters survivable without a teacher. Everything after it assumes you're running that method.

Then work chapters in order. Do not skip forward because a topic sounds interesting. Every chapter is load-bearing for the next.

Each chapter has:
- **Concepts** — the actual teaching
- **Code** — complete, working, explained line by line
- **Exercises** — with full solutions at the end of the chapter
- **Checkpoint** — a falsifiable test. Pass it or repeat the chapter.
